Key Insight · 打轴 03 / 07

Misconception vs Reality

别按句子剪

OLD LOGIC

句

只看整句 start / end，句子内部停顿容易漏掉。

NEW LOGIC

词

比较每个词的结束和下个词的开始，才有机会剪掉内部气口。

口播不是一句一句发生的，它是一条由词、停顿、呼吸和节奏组成的时间线。
